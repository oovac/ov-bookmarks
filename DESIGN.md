# Incumbent interface extension

OV uses Karakeep's existing global Tailwind tokens, Inter font, shadcn Button/Input/Dialog/Textarea and lucide-react icons. No new theme or token system. Text: foreground/muted-foreground; surfaces: background/muted/secondary; errors: destructive; focus: ring. Scalar spacing uses existing 2/3/4/5/6 units. Dialogs use the existing responsive portal. Scope: /dashboard/ov plus one navigation entry. Header 24px, body/actions 14px, metadata 12px. Density switches preserve the same data and actions.

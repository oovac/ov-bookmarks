# OV Bookmarks

Personal bookmark library for Ordo Vacui, preserving Karakeep compatibility. The user saves resources with independent favourite/review/case/future states, two taxonomies, personal judgement and separate task-specific model assessments. Project workspaces collect existing bookmark IDs. Import must be idempotent and preserve archived low-rated links.

Primary surface: /dashboard/ov. Mode: Operate. Build on the current Karakeep layout, Inter/system fallbacks, shadcn controls, neutral surfaces, semantic selected states, keyboard focus, readable compact lists. No redesign. Metadata search only, no full-text search without Meilisearch. History counts only opens initiated here.
